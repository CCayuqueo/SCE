# Desarrollo de SRC V1

La fuente de requisitos es el [plan maestro](../SRC_Plan_Maestro_Desarrollo_V1.md).
El [estado del desarrollo](DEVELOPMENT_PROGRESS.md) registra el alcance verificado
por fase. La [bitácora](DEVELOPMENT_LOG.md) ordena los cambios y las pruebas, y los
[ADR](TECHNICAL_DECISIONS.md) describen las decisiones de arquitectura.
